# Yoga Booking Website
Website built for my Web app dev course when attending Glasgow Caledonian university. We where provide ai generated code and instructed to make it work correctly. 

## Setup

### 1. Install dependencies

npm install

### 2. Seed the database

npm run seed

### 4. Run the app

npm start

Visit [http://localhost:3000](http://localhost:3000)

## Running Tests

npm test
